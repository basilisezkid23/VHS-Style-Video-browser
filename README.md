# Instructions

Requirements:

* Python 3.9 or newer

* VLC Media Player

Python packages:

```
pygame
numpy
python-vlc
```

Oh and also do not rename main.py unless you also update the command used to start the program.

The logs folder contains the MPEG Layer 4 files that appear in the program's log selection menu. (You can add your own videos as well)

The program does not require an internet connection once Python, VLC, and the required packages have been installed.
